# EMBARK Website

This repository contains the static website for the EMBARK CyberTraining project, a NSF-funded series of workshops for Early Career Ocean Professionals on how to develop essential skills to (re)use an ocean of data.

## Structure

- `index.html` — the main site page
- `css/style.css` — site-specific styles (layout, colors, cards, etc.)
- `assets/` — Bootstrap, Font Awesome, and other libraries
- `images/` — site images, including `images/logos/` for partner/advisor logos
